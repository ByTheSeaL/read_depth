# Read Depth

Look up words, phrases and sentences in technical writing, code, philosophy
and anything else as you read. It works through an Android app (share sheet,
text-selection menu or search box) and a Chrome extension (right-click
menu). Explanations come from the LLM you choose via OpenRouter. Lookups are
grouped into **channels**, areas of knowledge, so each explanation builds on
what you've already looked up.

See [PLAN.md](PLAN.md) for the design and build phases.
